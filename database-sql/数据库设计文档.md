## 二、分表详细设计

### 1. employee 员工信息表

用于存储商家后台管理员 / 员工账号信息

表格







|   字段名    |  数据类型   |   说明    |              备注              |
| :---------: | :---------: | :-------: | :----------------------------: |
|     id      |   bigint    |   主键    |         自增，主键索引         |
|    name     | varchar(32) | 在职部门  |    SQL 原始注释，非员工姓名    |
|  username   | varchar(32) |  用户名   | 唯一索引 idx_username，不可空  |
|  password   | varchar(64) |   密码    |             不可空             |
|   avater    | varchar(64) |   头像    |              可空              |
|    email    | varchar(32) |   邮箱    |             不可空             |
|    phone    | varchar(11) |  手机号   |             不可空             |
|     sex     | varchar(2)  |   性别    |             不可空             |
|   status    |   bigint    | 账号状态  | 默认 1；0 禁用，1 启用，不可空 |
| create_time |  datetime   | 创建时间  |              可空              |
| update_time |  datetime   | 更新时间  |              可空              |
| create_user |   bigint    | 创建人 ID |              可空              |
| update_user |   bigint    | 修改人 ID |              可空              |

- 索引：唯一索引 `idx_username(username)`

### 2. restaurant_category 菜品及套餐分类表

统一管理菜品、套餐两级分类

表格







|   字段名    |  数据类型   |   说明    |                备注                |
| :---------: | :---------: | :-------: | :--------------------------------: |
|     id      |   bigint    |   主键    |              自增主键              |
|    name     | varchar(32) | 分类名称  | 唯一索引 idx_category_name，不可空 |
|    type     |   bigint    | 分类类型  |  1 = 菜品分类，2 = 套餐分类，可空  |
|    sort     |   bigint    | 排序序号  |           默认 0，不可空           |
|   status    |   bigint    | 启用状态  |        0 禁用，1 启用，可空        |
| create_time |  datetime   | 创建时间  |                可空                |
| update_time |  datetime   | 更新时间  |                可空                |
| create_user |   bigint    | 创建人 ID |                可空                |
| update_user |   bigint    | 修改人 ID |                可空                |

- 索引：唯一索引 `idx_category_name(name)`

### 3. dish 菜品表

存储所有单点菜品基础信息

表格







|   字段名    |   数据类型    |     说明     |                备注                 |
| :---------: | :-----------: | :----------: | :---------------------------------: |
|     id      |    bigint     |     主键     |              自增主键               |

| category_id |    bigint     | 菜品分类 ID  | 关联 restaurant_category.id，不可空 |
|    price    | decimal(10,2) |   菜品价格   |                可空                 |
|    image    | varchar(255)  | 菜品图片地址 |                可空                 |
| description | varchar(255)  |   菜品描述   |                可空                 |
|   status    |    bigint     |   售卖状态   |    默认 1；0 停售，1 起售，可空     |
| create_time |   datetime    |   创建时间   |                可空                 |
| update_time |   datetime    |   更新时间   |                可空                 |

| update_user |    bigint     |  修改人 ID   |                可空                 |

### 4. dish_detail 菜品口味关系表

### 10. `order` 主订单表

订单主表，存储订单整体状态、收货配送信息

表格







|         字段名          |   数据类型   |     说明     |                             备注                             |
| :---------------------: | :----------: | :----------: | :----------------------------------------------------------: |
|           id            |    bigint    |     主键     |                           自增主键                           |
|         status          |    bigint    |   订单状态   | 默认 1，不可空1 待支付；2 待商家接单；3 制作中；4 待骑手取餐；5 配送中；6 骑手已送达；7 订单完成；8 订单取消 |
|         user_id         |    bigint    | 下单用户 ID  |                     关联 user.id，不可空                     |
|        username         | varchar(32)  |   用户姓名   |                          冗余，可空                          |
|        consignee        | varchar(32)  |    收货人    |                             可空                             |
|          phone          | varchar(11)  | 收货人手机号 |                             可空                             |
|       address_id        |    bigint    | 收货地址 ID  |                 关联 user_address.id，不可空                 |
|         address         | varchar(255) | 完整收货地址 |                          冗余，可空                          |
|       pay_status        |    bigint    |   支付状态   | 默认 0，不可空，关联 order_pay 表：0 未支付，1 已支付，2 退款 |
|         remark          | varchar(100) |   用户备注   |                             可空                             |
|     delivery_status     |  mediumtext  |   配送方式   |               1 立即送出，0 预约定时配送，可空               |
|   start_delivery_time   |   datetime   | 预约配送时间 |                             可空                             |
| estimated_delivery_time |   datetime   | 预计送达时间 |                             可空                             |
|      delivery_time      |   datetime   | 实际送达时间 |                             可空                             |
